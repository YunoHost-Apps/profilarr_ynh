# Upgrading from Profilarr v1

Profilarr v2 uses an incompatible database format (confirmed by upstream, no migration exists). </br>
Existing data (database, settings, linked arr configs) will be reset. You will need to go through the setup wizard again after the upgrade.

## IMPORTANT !!

If your Profilarr was previously installed under a path, for example: https://example.com/profilarr.
You will need to move it to a subdomain, for example: https://profilarr.example.com. </br>
This can be done after upgrading in YunoHost administration panel > Application > Profilarr > Operations > "Move the app to a different URL".
